# موقع معيار البناء

## هيكل الملفات
```
index.html          → صفحة الموقع الرئيسية (كل الأقسام: من نحن، معرض الصور، العلامات التجارية، فروعنا، لماذا نحن، تواصل معنا)
css/style.css        → كل تنسيقات وألوان الموقع
assets/images/       → شعار الشركة والصور
```

## كيفية الاستخدام
افتح ملف `index.html` مباشرة في أي متصفح لمعاينة الموقع، أو ارفع المجلد كاملًا على استضافة الموقع (حافظ على نفس هيكل المجلدات).

## لإضافة صور حقيقية لمعرض الصور
قسم "معرض الصور" في `index.html` يستخدم حاليًا أيقونات بدل صور حقيقية. لإضافة صوركم:
1. ضع الصور داخل `assets/images/`
2. استبدل عنصر `<svg>` داخل كل `.gallery-card` بعنصر `<img src="assets/images/اسم-الصورة.jpg">`
